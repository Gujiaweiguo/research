# 商业地产 AI 四维情报日报 · 11月26日

今天最值得留意什么：Anthropic 11-24 给 MCP 协议补上三块关键拼图——Skills（服务器随工具下发领域操作手册）、Tasks（后台长任务）、Elicitation（关键节点回来找人审批），文件直传也提上日程；「业务系统 × 通用助手」通道从「能问数据」升级为「能带方法、跑长流程、要人签字」。同日 OceanBase 在北京发布湖库一体 AI 数据平台 OceanLake 并开源 OceanSeek，披露平安寿险「对话经营数据」典型取数从 2-5 天缩至约 15 分钟——「经营问数」的收益量级第一次有了保险业一手数字（非商地）。商地需求侧（栏2）连续第六日无直接新证据；美国进入感恩节周，栏3 披露清淡。

## 1️⃣ AI 行业动态｜找锤子

**① Anthropic 扩展 MCP：服务器可发布 Skills、跑长任务、中途找人审批（11-24 官宣，11-25 中文见报，近窗补录）**
- 新事实：Skills over MCP 在 Claude/Claude Code 公测——MCP 服务器可在工具之外发布「技能包」（最佳实践、分步工作流、按账户/组织定制的 playbook），Claude 按需加载、不占常驻上下文，技能随服务器一起更新、用户无需单独安装。Tasks 与 Elicitation 转 GA：服务器可把耗时操作或完整 agent 循环放后台执行（Claude 继续别的工作、完成后取回结果），也可在花钱、删数据等节点暂停并向用户发起表单/链接确认后再继续。File Uploads（PDF/表格/图片直传服务器、不经过上下文窗口）即将推出。官方口径：MCP 月 SDK 下载量超 7 亿次、Claude 的 MCP 连接器超 1 万个；这些能力属于开放 MCP 规范及其扩展，任何兼容客户端可用，不锁 Claude。已披露用法：ZoomInfo 用 Tasks 跑更深的账户与联系人研究（此前需多轮提示）；Supabase 在创建付费项目/执行破坏性 SQL 前确认成本；GitHub 删仓库前要求输入仓库名；Shopify/HubSpot/Atlassian 已用 Skills 支持 Claude 端到端设计商户线上门店、完成客户 onboarding。
- 这把锤子能做什么/解决过什么：把「挂进通用助手的业务系统」从数据问答升级为长流程执行——下发领域操作知识（Skills）+ 后台异步执行（Tasks）+ 人在环节点审批（Elicitation）+ 文件交接（File Uploads）。这正是「数字员工跑租务/维保/账单流程」所需的协议件。
- 成熟度/适用条件：Skills 公测（Pro/Max/Ultra 默认开，Team 需管理员启用，Enterprise 即将）；Tasks/Elicitation GA 但 Team/Enterprise 在滚动推送；企业治理依赖 Enterprise Managed Auth（管理员一次授权全员自动连接）等扩展；统计数字为 Anthropic 口径，无第三方审计。
- 改变了什么判断：与 11-23 收录的 Yardi Virtuoso Connectors（商管 ERP 实时数据接入 Copilot/ChatGPT/Claude）直接叠加——通道标准升级后，租务跟进、报表生成、维保派单类长流程理论上可挂同一通道；但商管侧尚无服务器实现 Skills/Tasks 的披露，属供给能力先行，非客户落地。
- 证据：Anthropic 官方文章 https://claude.com/resources/articles/skills-over-mcp-tasks-and-more （页面未标精确日期；配套「MCP 两周年」官方帖为 11-24 https://blog.modelcontextprotocol.io/posts/mcp-turns-two/ ）；unite.ai 2026-11-24 https://www.unite.ai/anthropic-brings-server-supplied-skills-and-background-tasks-to-claude/ 【官方披露（一手全文核验）】

**② OceanBase 发布湖库一体 AI 数据平台 OceanLake、开源 OceanSeek；平安寿险取数 2-5 天→约 15 分钟（11-24，补录）**
- 新事实：11-24 蚂蚁 OceanBase AI 数据大会（北京）发布 OceanLake：湖库一体、离在线一体、多模数据统一治理、Agent 友好（效果观测与评测、长期与共享记忆、权限治理），统一管理结构化/半结构化/非结构化数据，为 Agent 提供实时业务上下文；同日宣布开源面向 Agent 场景的 AI 数据库 OceanSeek（湖库一体、多模态管理、混合检索、数据沙箱）。CEO 杨冰判断企业智能化转型远不及预期、瓶颈已从模型回到数据（「三座冰山」：私有×公有、多模态×结构化、乱×有序）。落地数字（OceanBase 口径）：蚂蚁灵光支撑 3,000 万+「闪应用」；平安寿险用 AI「读懂」保险、员工对话经营数据，典型取数交付从 2-5 天缩短至约 15 分钟；厦门航空经 DataPilot 让财务数据「开口说话」、支撑经营问数决策。另据会议报道，蚂蚁内部面向 Agent 的 MCP 访问量 4-9 月增长约 13.36 倍（媒体转述会议口径）。
- 这把锤子能做什么/解决过什么：给「经营问数」补数据底座——把分散、多模、乱的私有数据整理成 Agent 可用、可评测、带权限治理的资产。平安寿险证明该路线在大型金融企业的取数提速量级（天级→分钟级）。
- 成熟度/适用条件：客户数字为厂商披露（平安寿险/厦航为标杆案例，无第三方审计）；OceanSeek 开源即可用；湖库一体平台对数据治理起点要求高，中小组织直接采用门槛不低。
- 改变了什么判断：为栏4 跟踪的「月度经营数据汇编+问数」切口补充跨行业价值量级参照——「取数耗时」在保险、航空同样被量化为天级成本；但商管中小客户的数据规模与治理起点远低于平安/厦航，头部平台路径不可直接下移。
- 证据：新华网 2026-11-24 https://www.news.cn/tech/20261124/89e19da6a45d4b44800f320077f806e0/c.html 【官方披露（经新华网；客户数字为 OceanBase 口径）】

**③ 出门问问 TicNote 开放 MCP：语音/纪要成为办公 Agent 可调用的上下文（11-23，补录）**
- 新事实：TicNote 系列（录音卡片、耳机、AI 手表、App/Cloud）正式开放 MCP 服务，已连通腾讯 WorkBuddy 与百度文库库库AI；用户授权后，语音、转写与 AI 纪要可被外部 Agent 检索、分析、处理。与 WorkBuddy 的连接新增跨应用通知汇总（微信/飞书/钉钉等多平台通知统一整理）与双 AI 协作（Ask WorkBuddy/Shadow 提炼关键信息、整理待办，经 TicNote Watch 随时查看）；与库库AI 侧重知识查找与内容创作（录音纪要转为结构化资料与文档初稿）。
- 这把锤子能做什么/适用条件：「现场语音 → 转写/纪要 → 办公 Agent 工作流」的标准入口，硬件采集的真实信息成为 Agent 可调用的真实上下文。已上线（连接器区域搜索即连），限用户授权范围；无企业部署规模披露。
- 与商地的关联：商管巡场、招商洽谈、运营例会大量依赖口头信息——「语音纪要直接进 agent」若单价与准确率过关，是数字员工的输入侧配件；属工具级供给侧线索，商地无部署证据。

## 4️⃣ OPC 机会｜一个人能切的商地企业应用

**① 「月度资产/经营报告自动汇编+经营问数」跟踪条目更新：取数耗时的价值量级再获跨行业一手数字（非新立项）**
- 新证据：OceanBase 披露平安寿险「对话经营数据」典型取数交付 2-5 天→约 15 分钟、厦门航空 DataPilot 财务问数（11-24，见栏1 ②）。与 11-24 栏4 已引凯德数字（月度资产报告 80% 自动化、年省约 1,300 工时）互为印证：**「取数/汇编耗时」在保险、航空、头部商管三类组织均被独立量化为天级成本**。
- 对既有判断的影响：支持「中小商管｜资管运营岗｜月度经营数据汇编与问数」假设中「痛点真实、可量化、跨行业成立」的部分；同时提示反证——头部路径（凯德自建、平安用平台级产品）均非单人可复制，价值量级不能直接下移，中小商管买方样本仍缺。
- 最小工作流切口（不变）：只读接入客户上月 Excel/BI 导出（租金、费用、客流、能耗），自动生成带口径注释与异常标注的月度报告初稿+简单问数。单人可做、可交付、可维护（文件级只读，集成风险低）；主要风险仍是各客口径杂、客户已有 BI 报表模块，差异化必须落在「叙述+归因+口径解释」。
- 下一步验证指标（不变）：找 1 家中小商管用其上月真实数据盲测，度量报告初稿耗时（基线 X 小时→Y 小时）与口径问题数；初稿时间降 ≥70% 且客户愿按月付费，再谈产品化。本期待补关键证据：中小商管买方直接表达取数/汇编耗时（访谈或招标证据）。
